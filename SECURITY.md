# Segurança do Limivra

**Status:** fase inicial; não há release implantado.

Por favor, **não divulgue vulnerabilidades exploráveis publicamente**. Entre em contato com os mantenedores pela funcionalidade **Private vulnerability reporting** do GitHub, quando estiver habilitada para este repositório. Se indisponível, solicite um canal privado ao mantenedor sem incluir detalhes sensíveis em issue público.

Nunca envie senhas, chaves ADB, IMEI, seriais completos, capturas de apps bancários ou dados pessoais nos relatórios.

Escopo previsto: controle de subprocessos, consentimento de depuração Android, rede local, integridade das dependências, logs e acesso à sessão. Não oferecemos recompensa ou prazo de correção contratual.
