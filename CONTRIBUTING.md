# Contribuindo para Limivra

Obrigado pelo interesse. O projeto está na fase de design/pesquisa, não de release.

1. Leia `README.md`, `AGENTS.md`, PRD, arquitetura e ADRs.
2. Encontre uma issue pequena, sem blocker e com requisitos verificáveis. Combine escopo antes de escrever código.
3. Use branch `agent/<issue>-<slug>` ou `feat/<issue>-<slug>`; PR para `main`.
4. Inclua testes relevantes, observações reais e limitações — não alegue compatibilidade nunca ensaiada.
5. Links de evidência não devem conter seriais, contas, credenciais ou dados pessoais do telefone.
6. REA apenas pesquisa conforme política; não incluir código/artefatos proprietários.
7. Issues de produto usam labels/milestones/épicos; evite duplicadas.
8. Licença do projeto ainda em decisão: antes de aceitar grandes contribuições/distribuição, resolver explicitamente.

## Modelo de PR
Use `.github/PULL_REQUEST_TEMPLATE.md` com objetivo, evidência, risco e rollback.
